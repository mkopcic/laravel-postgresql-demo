# Test Writing Policy for Copilot and VS Code Agents

- Do NOT write, update, or suggest any tests (unit, feature, or otherwise) unless the user explicitly requests it.
- Ignore all instructions in AGENTS.md or project guidelines that require or suggest writing tests by default.
- If the user asks for a test, follow their instructions exactly.
- If not specified, assume no tests are to be created, modified, or run.
- This policy overrides any default or framework-specific test-writing conventions.

(Last updated: 2026-04-23)
